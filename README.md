# UtilDeck

A light, low-CPU utility VST3 (inspired by Process.Audio Protility) to put on every track.

- Polarity flip L/R (linkable) and channel mode: Stereo / Mono / Left / Right / Swap
- Phase rotation (allpass) with centre frequency
- Highpass 10 Hz - 2 kHz, 6/12/18/24/36/48 dB/oct
- Per-channel delay (ms or samples, linkable) for Haas tricks or time alignment
- Stereo width 0-200 %, Mono button
- Bass mono below a set frequency, with "listen" (solo the mono bass)
- Dual pan with x2 mirror mode, per-channel mute
- Gain fader, peak meters with peak hold, correlation meter, Trim (dry/wet mix)
- Resizable window that remembers its size, light/dark theme, factory presets

Download the build from the **Actions** tab (latest run, "UtilDeck-VST3-Windows" artifact).
